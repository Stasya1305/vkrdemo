# Прототип ИС мониторинга онлайн-продаж ПДС

Веб-прототип к ВКР Монанковой А. Г. «Проектирование информационной системы с целью повышения эффективности продаж негосударственного пенсионного фонда» (НИУ ВШЭ, Высшая школа бизнеса, направление «Бизнес-информатика», 2026).

## Что внутри

- **`index.html`** — дашборд руководителя: KPI, воронка конверсии, просроченные задачи и причины несопоставленных платежей.
- **`contract.html`** — карточка договора: статусы по трём трекам, лента событий, активные задачи, данные клиента.
- **`queue.html`** — очередь несопоставленных платежей: рабочий экран бэк-офиса с кандидатами и действиями.
- **`about.html`** — архитектура: трёхуровневый стек, модель данных, модули, алгоритм матчинга, целевые KPI.

## Стек

Чистый HTML / CSS / JavaScript без сборки — этого достаточно для статического прототипа и публикации через GitHub Pages. Не сервит реальную бизнес-логику: всё это иллюстративные данные.

## Соответствие архитектуре из работы

| Слой | Реализация в проекте | В прототипе |
|---|---|---|
| Представление | React SPA | статический HTML + минимальный JS (воронка, чекбоксы) |
| Бизнес-логика | FastAPI (Python) | заглушки — кнопки и формы без обработки |
| Данные | PostgreSQL, журнал append-only, JSONB | мок-данные внутри HTML |

## Бренд

Палитра и логотип — НПФ ГАЗФОНД пенсионные накопления. Фирменный синий (#0079C2) и кремовый фон для editorial-стилистики дашборда.

## Деплой

Сайт публикуется через GitHub Pages из ветки `main`. Полный URL — см. в Settings → Pages репозитория.
